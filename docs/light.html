Questions

Does the AI really run offline?

Yes. CopyCat bundles its own inference engine and downloads a model file once, from inside the app. After that, transforms and dictation work with your Wi-Fi switched off. There's no API key and no per-request cost.

How much disk space does it need?

The app is small; the models are your choice. A fast 0.5B text model is about 400 MB, the balanced default around 1 GB, and the English speech model 488 MB. Download only what you actually use.

Why does it need Accessibility permission?

CopyCat presses ⌘C and ⌘V for you and listens for your shortcuts — macOS puts both behind Accessibility. It's the same permission every clipboard and text-expansion tool asks for, and it's used for nothing else.

Is it on the Mac App Store?

No — and it can't be. App Store apps run sandboxed, which blocks the keystroke simulation that copy-to-slot and paste-from-slot depend on. Buying direct is the only way to get the full version, the same reason Alfred, Raycast and CleanShot sell direct too.

How many machines can I use it on?

The computers you personally work on. There's no license server counting them.
