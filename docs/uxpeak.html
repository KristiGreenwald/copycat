Questions

Good to know

Does the AI really run offline?

Yes. CopyCat bundles a local inference engine and downloads model files once, from inside the app. After that, transforms and dictation work with your Wi-Fi off. There is no API key and no per-request cost.

How much disk does it need?

The app itself is small. Models are your choice: a fast 0.5B text model is around 400 MB, the balanced default about 1 GB, and the English speech model 488 MB. Download only what you use.

Why does it ask for Accessibility permission?

CopyCat presses ⌘C and ⌘V for you and listens for your shortcuts — macOS gates that behind Accessibility. It's the same permission every clipboard and text-expansion tool needs, and it's used for nothing else.

Is this on the Mac App Store?

No, and it can't be. App Store apps run sandboxed, which forbids the keystroke synthesis that copy-to-slot and paste-from-slot depend on. Buying direct is the only way to get the full version — the same reason Alfred, Raycast and CleanShot sell direct.

One purchase, how many machines?

Use it on the computers you personally work on. There's no license server phoning home to count them.
